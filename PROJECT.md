# MDSI Website Project Rules

This repository contains the corporate website for MDSI Operations SRL.

## Structure
- index.html = English
- ro.html = Romanian
- fr.html = French

## Rules
When modifying the website:
1. Keep all three language versions aligned.
2. Keep the same visual identity and layout.
3. Keep the MDSI logo and tricolor branding.
4. Keep the tone professional, simple and corporate.
5. Focus on transport and logistics operations consulting.

## Do not
- Add aggressive marketing language.
- Add animations unless explicitly requested.
- Change the company identity.
- Remove sitemap.xml, robots.txt or CNAME.
